# Smart Study Planner – Instructions

## Setup
1. Copy the project to your web root (e.g., `C:\xampp\htdocs\smart-study-planner`).
2. Open `http://localhost/smart-study-planner/index.html` in your browser.

## Usage
- Register a new account, or log in if you already have one.
- Add a few courses and tasks.
- Use the Dashboard to see today’s schedule, urgent tasks, and overall stats.

## Tips
- Keep task estimates realistic (2–8 hours typical).
- Update task status and progress frequently for better prioritization.
- Select your preferred time (morning/afternoon/evening) in registration for better schedules.

## Troubleshooting
- Ensure JavaScript and localStorage are enabled in your browser.
- Clear browser cache if UI looks outdated.
- Use a modern browser (Chrome, Firefox, Edge, Safari).
