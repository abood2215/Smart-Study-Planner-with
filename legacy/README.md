# Legacy Files

This folder contains old PHP files that are no longer used in the current version of the application.

## Contents

- **index.php**: Old landing page (replaced by index.html)
- **login.php**: Old login page (replaced by login.html + API)
- **register.php**: Old registration page (replaced by register.html + API)
- **dashboard.php**: Old dashboard (replaced by dashboard.html + API)

## Why These Files Are Here

The project was migrated from a traditional PHP approach to a modern API-based architecture:
- **Old approach**: PHP pages with mixed HTML/PHP code
- **New approach**: HTML pages + JavaScript + RESTful API

These files are kept for reference only and are not used in the current application.
